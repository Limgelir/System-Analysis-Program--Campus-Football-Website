## 规则

- 裁判员填写区新增“弃权方”：正常比赛、主队、客队、双方。
- 选择主队弃权，默认主客比分 0–3；客队弃权默认 3–0。均可按实际判定修改。
- 选择双方弃权，两边比分清空，须手动填写。比分沿用 0–30 的整数范围。
- 切换弃权方前提示确认，取消保留所有输入；确认后清空进球记录和点球大战比分，并重设判定比分。
- 弃权比分不生成进球项、不要求进球球员，不计个人进球。没有名单也可填写弃权结果；红黄牌选择仍须符合本场名单规则。
- 红黄牌、裁判执法数据、第四官员记录单和监督报告沿用原有流程。
- 切回正常比赛，按当前比分重新生成待填进球项，恢复比分与逐条进球一致的校验；被清空的未保存输入不会自动还原。已保存内容仍可查阅报告历史。
- 系统主裁、管理员代填和管理员修订走同一校验。提交锁定、退回、修订原因、并发版本约束维持现有规则。
- 保存草稿不更新公开结果；正式提交、管理员修订同步公开弃权标记和比分。退回后仍展示上一正式结果，重提后替换。历史快照记录弃权方及前后内容。

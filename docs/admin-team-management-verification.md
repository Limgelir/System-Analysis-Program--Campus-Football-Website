# 管理员球队编辑与撤销误操作：本地验收

## 已确认规则

- 管理员可直接修改正式球队名称、负责人、球衣颜色、队员号码、队长及各项标记，按学号新增或删除队员。保存立即生效，不受报名或名单修改窗口限制；赛事须为当前启用且未结束。
- 复用球员端完整校验：球员账号启用、学籍通过、性别已填、号码非负且不重复、恰好一名队长，以及赛事人数、学院、外援、运训、足球特长生和合并标签限制。负责人可不参赛，但须有启用的球员账号。新入口不提供豁免。
- 有进行中的名单变更或待审角色变更时，须先处理或撤回，再直接修改。已撤销报名通过的球队须先恢复通过或重新审核。
- 名单修改新增正式批次；原批次与报告保留。当天、过去及已开始报告的比赛沿用原有名单保留规则。改名同步已有赛程的双方队名快照，管理员、裁判、球员公开赛程及导出使用新名字；历史报告留档不改写。
- “撤销退回球队补正”恢复原待审或自动失败状态、失败依据、审核信息及之前的补正范围。“撤销撤销报名通过（恢复通过）”恢复原通过状态和申请记录，当前正式名单、负责人、球队编号保持。
- 只允许申请及球队没有后续修改、重新提交或角色变化时撤销。版本单调增加，旧页面和重复请求会被拒绝。双方并发操作只允许一方成功。
- 仅保证本功能启用后产生且保存了完整恢复信息的退回／撤销可恢复；旧操作不显示恢复按钮。
- 恢复通过时解除仅由误撤销产生、之后未改动的名单冻结；已经开始报告或另行人工指定的比赛名单保留。误撤销前仍有效且未改动的名单草稿恢复可用。
- 管理员修改、原误操作和恢复操作均保留追加审计记录，并通知相关球员。

## 本地入口

- 管理员：<http://127.0.0.1:5228/admin-login>
- 球员：<http://127.0.0.1:5229/login>
- 随机密码及操作指南：项目 `.cache/admin-team-local-acceptance.txt`；完整虚构账号：`.cache/admin-team-preview.seed`，均不入 Git。

进入“队伍管理”，选择“可编辑示例队”，打开“管理员修改球队”。可改名、换负责人为 `ADM-LOCAL-3`、改号码、移除队员、添加 `ADM-LOCAL-4`。保存后检查当前名单和已有赛程的名字。原负责人为 `ADM-LOCAL-0`，原队长为 `ADM-LOCAL-1`。仅换负责人时原队长仍有球队管理权限，与球员端一致。

“球队报名审核”已准备“可撤销退回队”和“可恢复通过队”，可直接测试两种恢复。验收环境的报名和名单窗口已经关闭，可验证管理员操作不受窗口限制。

重建：先构建两个前端，在 `backend` 执行 `npm run preview:admin-teams`。停止：在 `.cache` 下创建 `admin-team-preview.stop` 文件；脚本关闭服务并仅删除自身随机测试库及临时上传目录。

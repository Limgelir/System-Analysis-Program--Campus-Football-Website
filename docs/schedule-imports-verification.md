## 使用

### 当前队伍名单

进入“队伍管理”，选择球队，在“当前名单”区域点击“导出当前名单 CSV”。导出时重新读取该队当前已生效的名单，包含赛季、比赛类型、队伍、名单版本、号码、姓名、学院、队长、守门员、赛事启用的球员标记和备注。历史批次和未来生效批次不会混入；未启用的运训／足球特长生标签不导出。

CSV 使用 UTF-8 BOM，兼容 Excel 中文读取；逗号、双引号、换行会转义，以公式符号开头的内容按文本导出。

### 批量新建赛程

1. 在当前启用赛季的“赛程管理”展开“批量新建赛程”。
2. 下载模板，或使用仓库根目录的 `赛程导入模板.xlsx`。首个“赛程”工作表从第2行开始填写；第二张表提供填写说明，不会导入。
3. 选择比赛类型、本批普通／五人制裁判安排、是否需要第四官员与监督。球队只能来自当前赛季和所选比赛类型，已撤销报名通过的球队不能用于新建比赛。
4. 上传文件并点击“检查并预览”。支持 `.xlsx`、`.xls`、UTF-8 `.csv`，最多200场、2MB。
5. 完全相同的队名自动对应。非完全相同的名称均弹窗确认，列出相似候选，也可选择该赛事中的其它球队。没有选定对应球队时不能提交；取消弹窗不会添加比赛。真正的新球队需先到队伍管理建立。
6. 核对日期、时间、对阵、场序及场地，点击“确认添加”。全部赛程在同一个事务中写入；出现错误时整批回滚。成功后按该赛事刷新列表，裁判在“裁判选派”中另行安排。

| 模板列 | 填写约定 |
| --- | --- |
| 场序 | 必填，1—50个字符，如 A1、J1、001；同赛季同比赛类型唯一 |
| 比赛日期 | 必填，YYYY-MM-DD；接受 Excel 日期单元格 |
| 开球时间 | 必填，24小时制 HH:mm，中国标准时间；00:00 有效，接受 Excel 时间单元格 |
| 主队／客队 | 必填，使用该赛事已有队名，不能对应同一支球队 |
| 比赛场地 | 樱花人草、129运动场、铁笼、嘉定人草、嘉定天然草、其它 |
| 其它场地说明 | 场地选择“其它”时必填（1—120字），固定场地留空 |

空白行忽略，但错误提示保留文件原始行号。公式和错误单元格须改为普通值。日期、时间、场地、重复场序及主客队相同等错误会阻止整批提交。预览有效30分钟，绑定管理员和原始输入；确认时再次检查赛季、球队及场序，数据变化要求重新预览。重复提交原预览会被拒绝，不会重复添加。

## 本地手动验收

在 `frontend` 执行 `npm run build`，随后在 `backend` 执行：

```powershell
npm run preview:schedule-imports
```

页面为 `http://127.0.0.1:5226/admin-login`。账号与随机密码写入被 Git 忽略的 `.cache/schedule-import-local-acceptance.md`，不使用日常账号。预览创建独立随机 MySQL 测试库，只监听回环地址；包括两个比赛类型、六支虚构球队及各队当前名单。

预览启动后在 `.cache` 生成以下样例：

- `赛程验收-精确队名.csv`：两场可直接预览确认的比赛。
- `赛程验收-相似队名.csv`：“土木学院队”需要确认对应“土木学院”。
- `赛程验收-错误行.csv`：非法日期、时间和缺少其它场地说明，不能提交。

停止预览可按 Ctrl+C，或创建 `.cache/schedule-import-preview.stop`；程序会关闭服务并清理本次随机数据库和临时上传目录。

## 实现约定

- `GET /api/team/:id/current-roster/export`：管理员下载当前有效名单。
- `GET /api/schedule/import-template`：管理员下载根目录模板。
- `POST /api/schedule/import-preview`：multipart 上传 `file`、`season_id`、`match_type`、`futsal`、`fourth_required`、`supervisor_required`、JSON字符串 `team_mappings`。
- `POST /api/schedule/import-confirm`：提交签名预览与 `preview_token`，确认成功返回数量及赛程ID。
- 单场和批量创建共用 `createScheduleInTransaction`，批量由外层事务统一提交，沿用现有场序、球队、裁判安排和报告生成逻辑。
